共性：所有 harness，同一副骨架

这条回路在 10 家代码里都能找到，一家例外都没有 —— 差异全在虚线的位置和形状
① 终止权普遍交给模型
dsh / Hermes / CASDK / Codex / Pi 均无 turn 硬上限；设上限的全是研究系框架（OpenAI 10、LangGraph 25、PydanticAI 50、LlamaIndex 20）—— 产品 harness 信任模型 + 靠护栏兜底。
② 多 Agent 只有三种姿势
换手 handoff ／ 借用 as_tool ／ 隔离派发 task。产品系（dsh/Hermes/CASDK/Codex）清一色隔离派发，没有一家做 agent 间移交。
③ 持久化收敛到 append-only
4 家独立发明了 JSONL 事件日志：dsh 事件溯源 v3 ／ Codex rollout ／ Pi 会话树 ／ CASDK transcript —— “日志是真相，视图是投影”成了行业共识。
④ 压缩已是标配
9/10 有上下文压缩（阈值 0.8×窗口、-16384、mid/post-turn……）；唯一没有的是 LangGraph 裸核 —— 从0实现时最容易漏掉的件。
⑤ 为 prompt cache 费尽心思
Pi 的 section 增量补丁、dsh 的“压缩调用=上次请求真前缀”、Hermes 的 memory 冻结快照 —— 省 cache 钱是架构级设计目标，不是优化项。
⑥ 官方集体自认“我不安全”
Hermes：“唯一边界是操作系统”；dsh：“未经审计、非唯一安全控制”；Smolagents：“非安全沙箱”；Pi：干脆不做，答案=容器化。

差异性 ②：多 Agent 编排只有三条路

换手（交接跑）· 借用（当工具用）· 隔离派发（派出去）—— 10 家各站一队，历史/上下文传递方式是本质区别
路线 A：换手 handoff（接力赛）
OpenAI SDK：transfer_to_X 工具，旧历史折叠成摘要文本再交接（handoffs/history.py:19-34）
LlamaIndex：return_direct 工具改写 next_agent 指针，全量共享 memory 不折叠
Pydantic AI：程序化换手（代码里显式切 run）
本质：同一个上下文容器换主人 —— 折叠不折叠是最大分歧
路线 B：借用 as_tool（外包）
OpenAI SDK：agent.as_tool() = 隔离运行（agent.py:606）≈ task
Pydantic AI：子 Agent 包成工具，独立 run/history，看不到父会话
本质：子代理是一次性函数调用 —— 父只拿返回值
路线 C：隔离派发 task（派工）—— 产品系全在这
deepagents：task 工具，只回最后消息（239K→7.9K tokens）
dsh：多后端派发（in-process / fork 播种父历史 / 进程外派活给 Codex、Claude Code）
Hermes：delegate_task + 阻断集（禁递归/禁写 memory）+ 心跳/steer
CASDK：subagents = 独立会话文件，可事后单独 resume
Codex：spawn_agent = 全功能子线程（审批硬关）+ 父子图持久化
Smolagents：子 agent = 解释器里的普通 Python 函数，能用代码编排
另类：Pi 干脆不做框架级多 Agent —— 子任务 = 工具内部嵌套 LLM 调用，循环保持单份。 隔离派发队内部又分两派：一次性派发（deepagents/OpenAI as_tool，调用即弃）vs 常驻线程（Codex 可续聊/Hermes 可 steer，像管理下属）。

差异性 ③：持久化四形态 × 压缩五时机

断点续跑能不能跨进程、分叉要不要复制、什么时候触发压缩 —— 代码层全是不同的赌注
形态 1 · 快照派 LangGraph checkpointer
每个 superstep 把全量图状态序列化落盘，按 thread_id 存档槽恢复。最强恢复语义（可时间旅行），代价是快照体积与写入频率。
形态 2 · 事件日志派 dsh · Codex · CASDK
append-only JSONL 是唯一真相，模型历史只是投影/派生。dsh 加 SHA-256 事件契约 + v2→v3 迁移样例；Codex fork 复制历史记 forked_from_ordinal；CASDK 闭源写盘只存对话不存文件系统。
形态 3 · 树派 Pi
会话是 JSONL 树（id/parentId），分支 = 改 leaf 指针，零复制；弃支由 LLM 生成 branch_summary 带进新分支 —— 最省存储的分叉设计。
形态 4 · 数据库派 Hermes
SQLite state.db（WAL+FTS5 全文检索，36 个加固模块），persist-before-execute 不变量：副作用执行前先落库；/undo /retry 回退到用户轮。
