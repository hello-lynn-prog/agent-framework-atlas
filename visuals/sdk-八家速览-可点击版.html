🚀 进化版选型指南(2026-10 两轮审计后 · 蓝字可点击跳详情)

学 agent,从 Pi 开始——140 行读完整个循环,看懂了它就看懂了所有 agent 的骨架。

写代码,用 Codex 或 Claude Code——产品级的安全兜底,开箱即干:Codex(审批+OS 沙箱双链) / Claude Code(六种权限模式)。

做业务 agent,用框架造、让 Codex/Claude 帮你写,框架按流程复杂度选:

  • 简单的领域助手 → OpenAI Agents SDK(注意它无记忆原语、无自动压缩,要自己补;详见 压缩 / 记忆 两行);
  • 多 agent 协作、关键节点要人审批的工作流 → LangGraph(checkpoint/interrupt/resume 是审批流最好底座,代价是学懂图模型+安全层自己搭,见 安全行);
  • 想快速起步 → deepagents——它是"LangGraph 预组装+一切皆中间件",压缩、记忆注入、文件权限都给你装好了,600+ 模型即插即用,但三件事要自己把关:shell 执行默认无隔离、权限只覆盖内置文件工具、跨会话长期记忆要自己沉淀(见 安全行)。

Hermes 和 DeepSeek Harness 是产品不是框架:Hermes 反射状态机没法静态调试、只能跑起来找错,但多供应商热切换+自动学习循环,天然是个人助理;DSH 一切皆插件、可派发给不同 agent,事件溯源 JSONL 让每次 run 可完整回放——但它是 TypeScript 栈,Python 程序接它要写桥接、养两套环境,所以对 Python 团队它只适合当素材库(偷它的事件日志和派发设计),不适合当地基。

最后两条铁律:① Codex 钉死 Responses 协议,接国产模型靠厂商兼容端点,协议通了但答案质量=模型能力×调校匹配×翻译保真度,三者相乘(详见 模型接入行);② 所有框架类默认全放行,上线前先给工具执行套容器或审批层——选错框架顶多返工,安全默认出事是数据泄露(详见 安全行)。
