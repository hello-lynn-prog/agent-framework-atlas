五站速查表

站钩子名时机 / 频率钩子形态deepagents 挂靠者
①before_agent循环前 · 1 次顺序执行钩子patch_tool_calls(修补)、memory(读)、skills(读)
②wrap_model_call / modify_request每圈调模型前 · N 次包裹器(可改流程)/ 请求改写器summarization(压缩)、系统提示、memory(注)、subagents(注)、unsupported_content(滤)、_tool_exclusion(剔)
③wrap_tool_call(前)+ interrupt每次工具执行前 · M 次包裹器 + langgraph 图中断权限 HITL(_fs_interrupt 编译的规则)
④wrap_tool_call(后)每次工具执行后 · M 次包裹器filesystem(冲突检测、大结果落盘)
⑤after_agent循环后 · 1 次顺序执行钩子(主包暂无;位由 langchain 预留)
N = 循环圈数;M = 工具调用次数。同一站上多个中间件按装配顺序叠层执行(洋葱模型:先挂的在外面)。
两个"不是钩子"的例外(易混):① 断点恢复——langgraph 在每个节点边界自动存 checkpoint,恢复 = 同 thread_id 重新 invoke,无中间件参与;② 沙箱安全——是执行器零件的材质(实现 SandboxBackendProtocol),不是挂在站上的检查。
